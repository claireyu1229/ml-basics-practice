# 機械学習の基礎 — 練習コード

AIを独学していた頃、オンライン講座を受講しながら書いた練習用のコードです。
scikit-learn を使って、代表的な機械学習アルゴリズムの基本的な使い方を一通り手を動かして学びました。

※ 学習目的のコードのため、コメントやファイル名は中国語で書かれています。

## 内容

| フォルダ | テーマ | 主な内容 |
|---|---|---|
| `01_机器学习概述` | 機械学習の概要 | KNNによる分類・回帰の考え方 |
| `02-KNN算法` | KNN（k近傍法） | 特徴量の正規化・標準化、アヤメ分類、交差検証とグリッドサーチ、手書き数字認識 |
| `03-线性回归` | 線形回帰（入門） | scikit-learn の線形回帰 API |
| `04-线性回归` | 線形回帰（応用） | ボストン住宅価格予測（正規方程式・勾配降下法）、正則化による過学習対策 |
| `05-逻辑回归` | ロジスティック回帰 | 乳がん予測、混同行列、適合率・再現率・F1値、通信会社の顧客離反分析 |
| `06-决策树` | 決定木 | タイタニック号の生存予測、線形回帰と回帰木の比較 |
| `07-集成学习` | アンサンブル学習 | ランダムフォレスト、AdaBoost、勾配ブースティング |
| `08-贝叶斯和特征降维` | ベイズ・次元削減 | XGBoost、ナイーブベイズによる感情分析、低分散法・PCA・相関係数による次元削減 |

## 使用技術

- Python
- scikit-learn / pandas / NumPy / matplotlib
- XGBoost, jieba
