# 機械学習の基礎 — 講座の練習コード

AIを独学していた頃に、オンライン講座を受講しながら書いた練習用のコードです。
Python と scikit-learn を使い、機械学習の代表的なアルゴリズムを「理論の整理 → 実装 → 評価」の流れで一通り手を動かして学びました。

各ファイルの冒頭にある docstring には、そのアルゴリズムの原理・数式・使いどころなどを自分用のメモとしてまとめています。
（学習当時のメモのため、コメントとファイル名は中国語です。）

---

## 学習の流れ

講座全体を通して、次の機械学習プロジェクトの基本的な流れを意識して書いています。

1. データの取得
2. データの前処理（欠損値の補完、One-Hot エンコーディングなど）
3. 特徴量エンジニアリング（正規化・標準化、次元削減、特徴量選択）
4. モデルの学習
5. 予測
6. モデルの評価（精度、MSE、適合率・再現率、F1値、AUC など）

---

## 各章の内容

### 01 機械学習の概要（`01_机器学习概述`）

KNN（k近傍法）を題材に、機械学習の基本的な考え方を学びました。

| ファイル | 内容 |
|---|---|
| `01_knn_分类思路.py` | KNN による**分類**：ユークリッド距離で近いK個のサンプルを探し、多数決でラベルを決める |
| `02_knn_回归思路.py` | KNN による**回帰**：近いK個のサンプルの平均値を予測値とする |

### 02 KNN アルゴリズム（`02-KNN算法`）

特徴量の前処理から、ハイパーパラメータの調整、モデルの保存までを学びました。

| ファイル | 内容 |
|---|---|
| `01_特征预处理_归一化.py` | `MinMaxScaler` による正規化（最小値・最大値の影響を受けやすいという弱点も整理） |
| `02_特征预处理_标准化.py` | `StandardScaler` による標準化（データ量が多い場合に適している） |
| `03_鸢尾花案例.py` | アヤメ（Iris）データセットの可視化（seaborn）と、KNN による分類・正解率の評価 |
| `04_交叉验证和网格搜索.py` | 交差検証と `GridSearchCV` による最適なハイパーパラメータ（K値）の探索 |
| `05_手写数字识别案例.py` | 手書き数字（28×28 ピクセル）の画像表示、KNN での学習、`joblib` によるモデルの保存・読み込み |
| `test.py` | 講座とは別に書いたアルゴリズム練習（バックトラッキングによる組み合わせ列挙） |

### 03・04 線形回帰（`03-线性回归`, `04-线性回归`）

| ファイル | 内容 |
|---|---|
| `03-线性回归/01_线性回归API入门.py` | `LinearRegression` の基本的な使い方、重み（w）とバイアス（b）の意味 |
| `04-线性回归/01_波士顿房价预测_正规方程解法.py` | ボストン住宅価格の予測を**正規方程式**で解く |
| `04-线性回归/02_波士顿房价预测_梯度下降解法.py` | 同じ問題を**勾配降下法**（`SGDRegressor`）で解き、正規方程式と比較 |
| `04-线性回归/03_正则化方式解决过拟合问题.py` | 未学習・過学習の再現と、**L1正則化（Lasso）・L2正則化（Ridge）**による過学習対策 |

評価指標として MAE（平均絶対誤差）・MSE（平均二乗誤差）・RMSE（二乗平均平方根誤差）を使っています。

### 05 ロジスティック回帰（`05-逻辑回归`）

| ファイル | 内容 |
|---|---|

| ファイル | 内容 |
|---|---|

## 使用技術

- **言語**：Python 3
- **機械学習**：scikit-learn, XGBoost
- **データ処理**：pandas, NumPy, SciPy
- **可視化**：matplotlib, seaborn
- **その他**：jieba（中国語の形態素解析）, joblib（モデルの保存）

## 実行方法

```bash
pip install scikit-learn pandas numpy scipy matplotlib seaborn xgboost jieba joblib

# 各章のフォルダに移動してから実行します（データは相対パスで読み込んでいます）
cd 02-KNN算法
python 03_鸢尾花案例.py
```

※ 講座の環境に合わせて書いたコードのため、ファイルによってはデータの置き場所（`./data/` など）を調整する必要があります。
